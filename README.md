# 📚 Book.com

A modern web application for exploring Pashto poetry, revolutionary writings, and historical literature.  
Book.com is designed as a clean, animated, and user-friendly digital library experience.

---

 ✨ Features

- 📖 Curated collection of books and poetry
- 🛒 Shopping cart system (add/remove books)
- 📱 Fully responsive design (mobile + desktop)
- 🎨 Smooth UI animations using Framer Motion
- 🔍 Categorized browsing (Pashto, Revolution, Popular, etc.)
- ⚡ Fast and modern React UI

---

🛠️ Tech Stack

- React.js
- Tailwind CSS
- Framer Motion
- JavaScript (ES6+)
